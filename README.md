# AdminPro - Professional Admin Dashboard Template

![AdminPro Dashboard](./screenshots/dashboard.png)

A complete, production-ready admin dashboard template built with Next.js, TypeScript, and Tailwind CSS. Perfect for SaaS products, B2B applications, and internal tools.

## ✨ Features

- 🔐 Authentication system (login/logout)
- 👥 User management (CRUD, pagination, search, export CSV)
- 📊 Advanced analytics with interactive charts
- 📅 Calendar with events
- 💰 Billing & invoices page
-  Products management
- 📋 Activity log
- 🌙 Dark/Light mode
- 🌍 Multi-language (ES, EN, FR, PT, DE)
- 🎨 Customizable primary color
- 📱 Fully responsive
- 🖱️ Drag & drop widgets
- 🔔 Notifications system
- 👤 User profile management
- 🔑 Role-based permissions (Admin, Editor, Viewer)

## 🛠️ Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS v4
- Recharts
- Lucide Icons
